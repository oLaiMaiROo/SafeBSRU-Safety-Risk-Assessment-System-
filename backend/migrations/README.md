# migrations

การเปลี่ยนโครงสร้างของฐานข้อมูล `safety_db` ที่มีข้อมูลอยู่แล้ว รันตามลำดับเลข ไฟล์ละครั้ง
วิธีรัน การสำรองข้อมูล และการย้อนกลับ ดูที่ [`../DATABASE.md`](../DATABASE.md)
ถ้าติดตั้งบนเครื่องใหม่ (ฐานข้อมูลว่าง) ไม่ต้องใช้ไฟล์ในโฟลเดอร์นี้ ให้ใช้ `node setup-db.js`

| ไฟล์ | สิ่งที่ทำ |
|---|---|
| `001_relations_and_cleanup.sql` | เพิ่มตาราง `departments`, `severity_levels`, `report_images` และ foreign key ของ `reports`, เพิ่ม `incident_date` และ `handled_by`, แยกข้อมูลผู้แจ้ง, เข้ารหัสรหัสผ่านแอดมินด้วย bcrypt, ลบคอลัมน์เดิมที่ย้ายข้อมูลแล้ว |
